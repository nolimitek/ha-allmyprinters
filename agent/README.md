# AllMyPrinters Agent (Home Assistant app)

Runs the AllMyPrinters agent inside Home Assistant: your 3D printers, spools and filament boxes in one place, with print
start, booking of used filament and phone notifications — no separate Docker needed.

Works with Klipper (incl. Anycubic with Rinkhals, Snapmaker U1), Bambu Lab (LAN), Prusa (PrusaLink), OctoPrint, Elegoo,
Creality, Flashforge and Anycubic (LAN).

See the **Documentation** tab for setup.
